## Project Goal

The goal of this project is to compare Merge Sort, Quick Sort, Shaker Sort, and Heap Sort using the number of element-to-element comparisons.

## Required Input Sizes

- n = 4
- n = 6
- n = 8

## Main Tasks

1. Generate all permutations for each required value of n.
2. Implement the four sorting algorithms.
3. Use the same comparison-counting method for all algorithms.
4. Run all permutations through all four algorithms.
5. Record comparison counts.
6. Identify the best 10 cases.
7. Identify the worst 10 cases.
8. Calculate the average number of comparisons.
9. Analyze the results.
10. Complete the final report and screencast.
